# Polly's Polygon Playground

A hands-on 3rd grade geometry game covering shapes, angles, perimeter, and area.

**Play it:** https://raw.githack.com/Akbar300/pollys-polygon-playground/main/index.html

**GitHub Pages link:** https://akbar300.github.io/pollys-polygon-playground/ (this works once GitHub Pages is turned on for the `main` branch in the repo settings)

Open either link in Safari or Chrome. On iPhone or iPad, use Share and then Add to Home Screen to open it like an app.
